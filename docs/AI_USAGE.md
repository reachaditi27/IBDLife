# Development tools, AI assistance, and credits

IBDLife has used AI assistance in its development. The project owner's disclosure
for the application is reproduced here so source reviewers have the same context.

## Project owner's disclosure

> I used ChatGPT and OpenAI's Codex to help develop IBDLife, my first iOS application.
> Although I had prior programming experience in Python and Java, I was new to
> SwiftUI and Xcode.
>
> AI Tools Used:
> - ChatGPT: Helped me learn unfamiliar development concepts, understand SwiftUI,
>   explore technical solutions, and troubleshoot problems.
> - OpenAI Codex: Generated much of the SwiftUI code based on my designs, feature
>   requirements, and instructions. I used Codex iteratively, reviewing the results,
>   identifying issues, and requesting modifications until features worked as intended.

## Recorded development process

- This development conversation began with an existing SwiftUI/Xcode project and
  a working, manually tested onboarding flow. The project owner provided Figma
  reference screenshots for the remaining screens and directed the desired flows.
- OpenAI Codex assisted substantially with SwiftUI implementation, navigation,
  models and persistence, schedule calculations, tests, debugging, simulator checks,
  and subsequent feature revisions. Codex also helped prepare repository comments
  and documentation for public review.
- The project owner reviewed the app, tested it on Simulator and a physical iPhone,
  supplied feedback, and directed changes. The Git author field alone does not
  distinguish student-written from AI-assisted code.
- The repository uses Apple's frameworks and development tools. No third-party
  Swift package dependencies are declared. Figma exports are retained under
  `DesignReferences` as design references.

## Submission context

The implementation notes above describe the development conversation and do not
certify sole authorship or contest eligibility. The application contains the
owner's account of their contributions; any additional assistance or assets used
outside this conversation should also be disclosed there.

The [2026 Congressional App Challenge rules](https://www.congressionalappchallenge.us/wp-content/uploads/2026/05/2026-CAC-Rules.pdf)
allow AI support with full disclosure and require significant personal contributions
and technical understanding. The participant should be able to explain the app's
architecture and important algorithms and accurately describe which work they did.
This document should accompany, not replace, the disclosure requested by the
submission form.
